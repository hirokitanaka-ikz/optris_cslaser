# Optris CSLaser Pyrometer Monitor
This program is a GUI application for communicating with an Optris pyrometer CSLaser series using Python.
The application allows users to control a pyrometer, record and visualize the data.
As a virtual environment, this program uses Pixi (https://pixi.sh/latest/)

## Quick start
1. Go to Pixi webpage (https://pixi.sh/latest/) and install pixi
2. Run "setup.bat"
3. Run "run.bat"
